## 📌 প্রোজেক্ট পরিচিতি (Project Overview)

**বাজার দর (BazarDor)** হলো নিত্যপ্রয়োজনীয় খাদ্যপণ্যের প্রতিদিনের খুচরা ও পাইকারি বাজারদর পর্যবেক্ষণের একটি আধুনিক ও পূর্ণাঙ্গ ওয়েব অ্যাপ্লিকেশন। সাধারণ ভোক্তা ও ক্রেতাদের জন্য দেশের বিভিন্ন বাজার (যেমন: কারওয়ান বাজার, গ্রীন মার্কেট, সদর বাজার ইত্যাদি) থেকে সংগৃহীত চাল, ডাল, তেল, সবজি, মাছ, মাংস ও মসলার সঠিক ও হালনাগাদ তথ্য এক ঠিকানায় তুলে ধরা হয়েছে।

## 🌟 মূল বৈশিষ্ট্যসমূহ (Key Features)

1. **🔴 লাইভ প্রাইস টিকার (Live Infinite Price Marquee Ticker):**
   - নেভবারের ঠিক নিচে নিরবচ্ছিন্নভাবে চলমান প্রাইস স্ট্রিপ।
   - প্রতিটি পণ্যের ইমোজি, নাম, আজকের দাম এবং মূল্য পরিবর্তনের শতকরা হার (▲ বৃদ্ধি/▼ হ্রাস) রিয়েল-টাইমে প্রদর্শিত হয়। মাউস হোভার করলে টিকারটি সাময়িক থেমে যায়।

2. **📈 বাজার মুভার্স — আজ দাম বেড়েছে ও দাম কমেছে (Market Risers & Fallers):**
   - হোমপেজে পূর্ববর্তী দিনের তুলনায় শীর্ষ ৬টি দাম বৃদ্ধি পাওয়া পণ্য (▲) এবং শীর্ষ ৬টি দাম হ্রাস পাওয়া পণ্য (▼) সহজে দৃশ্যমান কার্ড গ্রিডে দেখানো হয়েছে।

3. **🔍 ফিল্টারিং, সার্চ এবং অ্যাডভান্সড সর্টিং (Advanced Sorting & Filtering):**
   - বাংলা সংখ্যার মান বুঝে সংখ্যাভিত্তিক নির্ভুল সর্টিং ব্যবস্থা: **ডিফল্ট**, **দাম: কম থেকে বেশি**, এবং **দাম: বেশি থেকে কম**।
   - তাৎক্ষণিক পণ্য সার্চ এবং ৮টি ক্যাটাগরি পিলের মাধ্যমে দ্রুত ফিল্টার করার সুবিধা।

4. **🔒 সুরক্ষিত বিস্তারিত তথ্য পেজ ও বাজারভিত্তিক তুলনামূলক দর (Protected Product Details Page):**
   - যেকোনো পণ্যের বিস্তারিত পেজ (`/product/[slug]`) একটি সুরক্ষিত রুট (Protected Route)। লগইন ছাড়া প্রবেশ করতে চাইলে স্বয়ংক্রিয়ভাবে টোস্ট নোটিফিকেশন সহ সাইন-ইন পেজে রিডাইরেক্ট করে।
   - পণ্যের বিস্তারিত পেজে সর্বনিম্ন দাম, সর্বোচ্চ দাম ও গড় দামের সামারি কার্ড।
   - কারওয়ান বাজার, সদর বাজারসহ বিভাগভিত্তিক (ঢাকা, চট্টগ্রাম, রাজশাহী, খুলনা, সিলেট ইত্যাদি) বাজারদরের তুলনামূলক রেসপনসিভ টেবিল ও সার্চ সুবিধা।

5. **🔐 বেটার-অথ (BetterAuth) প্রমাণীকরণ ও প্রোফাইল আপডেট (Auth & Profile Update):**
   - ইমেইল/পাসওয়ার্ড ও সোশ্যাল লগইন (Google, GitHub) সমর্থন।
   - পরীক্ষক ও মূল্যায়নকারীদের সুবিধার জন্য এক-ক্লিকে তাৎক্ষণিক ডেমো সাইন-ইন অপশন।
   - **তথ্য আপডেট ফিচার (Challenge C3):** ব্যবহারকারীর প্রোফাইল রুট (`/profile`) থেকে ডেডিকেটেড রুট (`/profile/update`)-এ গিয়ে BetterAuth নির্দেশিকা অনুযায়ী নাম হালনাগাদ করার পূর্ণাঙ্গ সুবিধা।

6. **📱 সম্পূর্ণ রেসপনসিভ ও আধুনিক ডিজাইন (100% Responsive UI):**
   - মোবাইল, ট্যাবলেট এবং ডেস্কটপ সব ডিভাইসে নিখুঁতভাবে দেখার উপযোগী ক্লিন গ্রিন ও সাদা থিমের প্রিমিয়াম ফন্ট ও উপাদান।
   - মসৃণ কাস্টম লোডার ও কঙ্কাল অ্যানিমেশন (Skeleton Loaders), ফ্রেন্ডলি ৪০৪ (Not Found) পেজ এবং এরর বাউন্ডারি হ্যান্ডলিং।

## 🛠️ ব্যবহৃত প্রযুক্তিসমূহ (Technologies Used)

| প্রযুক্তি | ব্যবহার ও ভূমিকা |

| **Lucide React** | আধুনিক ও ক্লিন ভেক্টর আইকন সেট |

## 📂 প্রোজেক্টের ফোল্ডার গঠন (Project Structure)

```text
├── public/                     # স্ট্যাটিক অ্যাসেট ও ছবি (bazar-hero.png, logo-icon.png)
├── src/
│   ├── app/
│   │   ├── api/
│   │   │   └── auth/[...all]/  # BetterAuth এপিআই রুট হ্যান্ডলার
│   │   ├── category/[slug]/    # ক্যাটাগরি ভিত্তিক পণ্য তালিকা ও লোডিং স্কেলিটন
│   │   ├── product/[slug]/     # সুরক্ষিত পণ্যের বিস্তারিত ও বাজারভিত্তিক দাম
│   │   ├── profile/            # ব্যবহারকারীর প্রোফাইল
│   │   │   └── update/         # প্রোফাইলের তথ্য আপডেট ফর্ম
│   │   ├── signin/             # সাইন ইন পেজ ও সোশ্যাল লগইন
│   │   ├── signup/             # রেজিস্ট্রেশন পেজ
│   │   ├── not-found.tsx       # কাস্টম ৪০৪ পেজ
│   │   ├── error.tsx           # গ্লোবাল এরর বাউন্ডারি
│   │   ├── loading.tsx         # হোম পেজ লোডিং স্কেলিটন
│   │   ├── page.tsx            # হোমপেজ (হিরো, রাইজার্স, ফলার্স, সকল পণ্য)
│   │   └── layout.tsx          # রুট লেআউট (নেভবার, ফুটার, টোস্টার, অথ প্রোভাইডার)
│   ├── components/             # পুনর্ব্যবহারযোগ্য কম্পোনেন্টসমূহ (ProductCard, Navbar, etc.)
│   ├── context/                # AuthContext (সেশন ও ইউজার স্টেট ম্যানেজমেন্ট)
│   └── lib/                    # হেল্পার ফাংশন, এপিআই ক্লায়েন্ট, বাংলা কনভার্টার ও টাইপস
├── next.config.ts              # Next.js কনফিগারেশন
├── tailwind.config.ts          # Tailwind কালার ও থিম কনফিগারেশন
└── package.json                # ডিপেনডেন্সি ও স্ক্রিপ্টসমূহ
```

## 💻 স্থানীয়ভাবে চালানোর নিয়ম (Local Setup & Installation)

১. রিপোজিটরিটি ক্লোন করুন:
```bash
git clone https://github.com/gra-kafi/BazarDor.git
cd BazarDor
```

২. ডিপেনডেন্সি ইনস্টল করুন:
```bash
npm install
```

৩. ডেভেলপমেন্ট সার্ভার চালু করুন:
```bash
npm run dev
```

৪. ব্রাউজারে প্রবেশ করুন: `http://localhost:3000`
